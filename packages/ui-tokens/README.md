# ui-tokens

Dark & Gold tema tokenleri: koyu karbon (#121212) zemin, elektrik mavisi/şampanya altını vurgu renkleri, Inter/SF Pro tipografi, glassmorphism stil değişkenleri.

`src/theme.ts` içinde `colors`, `typography`, `spacing`, `radii` olarak dışa aktarılıyor; mobilde RN `StyleSheet` değerleri olarak kullanılıyor, ileride web'de Tailwind config olarak tüketilecek.
